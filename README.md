## Included Tools

### 🎵 JesterAudio
An ad-free batch audio converter for YouTube that extracts **WAV** and **MP3** files directly from video links. Designed for speed and simplicity, it supports queuing multiple URLs at once for clean, uninterrupted downloads.

### 🌐 JesterWire
An automated packet capture and network analysis tool built to make Wireshark-style traffic inspection faster and easier to understand. JesterWire automates routine packet filtering and translates complex network activity into clear, readable summaries.
